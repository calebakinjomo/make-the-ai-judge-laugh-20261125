One office-life joke, written to be read aloud in one breath — true to the
office, with a surprising turn, and tight.

> I asked my boss for a raise. He said money isn't everything — then gave himself a bonus.

## How it works

`main.py` writes the joke to `/output/entry.txt` (one line, under 200
characters). Run it with:

```sh
python3 main.py
```
